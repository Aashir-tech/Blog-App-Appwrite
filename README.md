# React Blog Application 📝  

A full-featured **React Blog Application** built with **Appwrite**, enabling users to **create, edit, and manage blog posts** with a **Rich Text Editor (RTE)**. It also supports **authentication (login/signup)** and allows users to **comment on posts**.

## ⭐ Features  
- **User Authentication**: Sign up & login with Appwrite authentication.  
- **Create & Edit Posts**: Write and edit blog posts with a Rich Text Editor (RTE).  
- **View Posts**: Browse posts written by other users.  
- **Commenting System**: Engage with posts by adding comments.  

## 🚀 STAR Method  

### **Action:**  
Developed a React-based **blog application** using **Appwrite** for backend services. Implemented **JWT authentication**, a **Rich Text Editor (RTE) for blogging**, and a **commenting system** for user engagement.  

### **Result:**  
Enabled seamless blog creation and interaction, enhancing user engagement and content management while ensuring **secure authentication** and **real-time updates**.  

## 🛠 Tools Used  
- **Frontend:** React.js, React Router, Redux for state management  
- **Backend & Database:** Appwrite  
- **Authentication:** Appwrite Auth  
- **Editor:** Rich Text Editor of tinyMCE  
- **Styling:** Tailwind CSS / CSS Modules  
- **Deployment:** Netlify  

## 📜 Setup Instructions  
1. Clone the repository:  
   ```sh
   git clone https://github.com/Aashir-tech/Blog-App-Appwrite.git
   cd react-blog-app
   ```

2. Install dependencies:
  ```sh
  npm install
  ```
3. Configure Appwrite settings Project ID, Database ID, Collections in .env or directly in your code.
4. Run the application
   ```sh
   npm start
  ```
